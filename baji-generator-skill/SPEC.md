# V2.0 规格与限制

- 默认七种材质、银边、白背景、1024 PNG；每种效果默认同时输出 640×640、58 帧、40ms/帧、无限循环的旋转 GIF。明确材质时只输出指定项；`--no-animation` 禁用动画。
- 工作分辨率至少 1024；普通图用 Lanczos 与轻锐化，低色数小图用最近邻保留像素感。
- 非方图依据透明内容或边缘视觉重心裁切，失败时稳定中心裁切；这不是语义主体、人脸或宠物识别，复杂背景可能需要人工调整源图。
- 材质和摄影效果均由 Pillow 程序生成，同一种子可重复。白瓷、拉丝银葱、两种镭射、磨砂、毛绒饼干均以保留原图可辨识度为优先。
- V1.2 统一使用约 0.85% 直径的细金属正面环和约 0.3% 的技术性内边；六种材质均复用连续 smoothstep 鼓面映射、程序化球冠明暗、重做的双区对角膜高光及紧凑接触阴影。
- V1.3 将漫反射凸面明暗、径向边缘暗化和镜面膜高光彻底分层。暗部仅使用中性乘法亮度调制；高光在单通道 `L` 遮罩上生成并只模糊 alpha，再应用于纯白实色层，因此高光只增亮、不产生灰黑边缘。
- 透明背景导出 RGBA，并保留半透明投影；因此空白区可能有非零 alpha。
- GIF 使用 Pillow 程序化伪 3D 转台。V1.2 通过非线性列网格近似曲面透视，以前后椭圆轮廓间的连接面生成连续侧壁，并使用柔和径向金属背板；暂不包含真实别针。透明背景 GIF 为保证边缘和阴影稳定，会合成到近白背景；静态透明 PNG 仍保持 alpha。
- V1.3 侧壁厚度约为直径 1.9%，完全侧面使用圆角卷边轮廓；背面改为低对比度冲压金属渐变和两条极浅压痕，不使用球形大亮斑。暂不包含真实别针。
- V1.5 的 `BadgeModelConfig` 集中管理半径、正面球冠、卷边、总厚度、背面弧度、透视和预留背面配件接口。默认深度函数为连续轴对称曲面；正面中心比边缘突出约 5.8% R，背面弧度仅 1.2% R。
- `model_renderer.py` 对旋转后的正面、卷边、侧壁和背面执行解析射线求交，以相机深度选择最近命中；数值切线处按不透明实体的单一扫描线区间补齐，因此侧面无孔洞、碎片或独立竖杆。
- 正面纹理由真实曲面交点 `(x,y)` 计算连续 UV，只应用到 `SURFACE_FRONT`；卷边、侧壁和背面使用独立金属材质。旋转法线进入固定摄影棚灯光坐标，所以高光随模型转动。
- 静态 PNG 调用同一渲染器的 yaw=0°；GIF 默认 58 个等角度帧。26 项自动测试覆盖旧功能、深度/法线/拓扑、z-buffer、UV、危险帧、纹理隔离、白色素材和透明 alpha。
- V1.5 不实现背面别针。`back_accessory=None` 是后续非轴对称配件入口；主体模型验收后再独立加入针、针座和卡扣。
- V2.0 将 V1.5 解析模型保留为 Pillow/NumPy 兼容模式，并新增固定 58mm OBJ 主模型。高质量 OBJ 后端包含真实三角网格针、铰链、两个安装脚和卡扣；所有硬件参与逐像素深度测试。
- V2.0 三材质区为 `front_art`、`rim_metal`、`back_metal`。正面 UV 由白模 Y/Z 坐标映射；用户纹理不得进入卷边、背壳或硬件。特殊材质改变正面纹理和世界空间反射参数。
- `--backend auto` 的能力顺序为 Blender、包内固定 OBJ 本地 3D、可用 GLB/WebGL、Pillow 兼容模式。当前包不附带浏览器运行时或未经验证的 GLB；明确指定不可用后端会失败并说明原因。
- Blender 路径使用 `blender --background`、固定 OBJ、Principled BSDF、正交相机和同一场景多角度渲染；当前交付环境未安装 Blender，最终像素验收使用 OBJ CPU 后端。
- Pillow 兼容模式没有真实背面硬件，不得将其描述为真实别针 3D。所有模式继续支持静态 PNG、旋转 GIF和既有输入/材质/包边/背景参数。
- 选择面板最终美术未随 V1 提供，`assets/style-selection-panel.png` 为预留位置；无面板时使用 SKILL.md 中固定文字。
- 会话状态由宿主上下文维护，无数据库。多图 1–9 张直接处理，超过 9 张需宿主确认。
- 旧源码检查：当前工作区未找到 `main4`–`main8` 或 `index4`；发现的旧网页文件不包含指定核心版本，V1 独立实现。
